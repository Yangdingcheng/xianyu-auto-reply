# 闲鱼自动回复助手 🐟

给闲鱼卖家的本地自动客服：**关键词回复 + AI 接入 + AI 议价守底价 + 卡密自动发货 + 人工接管 + 管理后台**。
参考了市面主流方案（闲鱼管家类产品与多个开源项目）的功能清单重新实现，代码原创、结构解耦——
回复引擎与闲鱼连接层分离，**全部核心逻辑都能离线演示和测试**，不绑任何账号就能先跑起来看效果。

## 功能一览

- **分层回复引擎**：商品专属规则 → 关键词（精确/包含/正则、优先级、多回复随机、变量替换） → 议价守卫 → AI → 默认回复
- **AI 接入**：OpenAI 兼容协议，DeepSeek / 通义千问 / OpenAI / 硅基流动等填个地址就能用；带多轮上下文，系统提示内置「绝不低于底价、遇纠纷转人工」约束
- **AI 议价守卫**：钱的事不让大模型自由发挥——按「底价 + 让价阶梯 + 最大轮数」做确定性决策：150 砍价 → 还 193 → 还 187 → 185 成交，全程不越底线
- **卡密自动发货**：付款事件触发，从卡密池按商品原子取用并发送；库存不足自动钉钉/企业微信告警
- **人工接管**：检测到卖家本人在手机上回复后，自动暂停该会话（默认 10 分钟），不和真人抢答
- **防打扰**：工作时间、单会话冷却、黑名单、离线回复、默认回复 24h 只发一次
- **通知推送**：钉钉 / 企业微信 Webhook（发货、缺货、转人工、登录失效）
- **管理后台**：本地网页一屏搞定——统计、规则增删、卡密补货、日志、在线测试（干跑看决策）
- **多账号**：配置里可挂多个账号，各自独立状态与日志
- **收货致谢**：买家确认收货后自动发送感谢语（可在配置里关）

## 快速开始（零依赖，先跑演示）

```bash
python main.py --demo
```

你会看到一段完整的模拟对话：问在不在 → 问包邮 → 三轮砍价成交 → 付款自动发卡密 →
卖家手动接管后机器人自动闭嘴 → 没命中规则的问题走默认回复。

```bash
python main.py --test-reply "150卖不卖" --item 1001   # 单条消息看决策
python main.py --web                                    # 管理后台 http://127.0.0.1:8765
python run_tests.py                                     # 34 项核心逻辑测试
```

## 真实接入闲鱼

1. `pip install -r requirements.txt`（只有真实模式需要 `websockets`，其余全是标准库）
2. 复制 `config.example.json` 为 `config.json`：
   - `ai.api_key` 填你的大模型 Key（不填则 AI 层自动跳过，只走规则）；
   - `items` 里把商品 ID、标价、**底价**改成你自己的；
   - `accounts` 里账号的 `cookie_file` 指向本地 Cookie 文件。
3. 把闲鱼网页版（goofish.com）登录后的 Cookie 存进 `cookies/main.txt`（**只存本地，不要提交到任何仓库**）。
4. 复制 `rules.example.json` 为 `rules.json` 改成你的话术；卡密放 `data/cards.json`（格式见 `cards.example.json`）。
5. `python main.py --live`

连接流程：Cookie → MTOP 换 IM token → WebSocket 长连接（`/reg` 注册、15 秒心跳、断线重连）。
登录失效会立即停机并推送通知，不会狂试触发风控。

## 议价守卫怎么工作

每个商品可配 `floor_price`（底价）与 `max_rounds`（最多让价轮数）。
买家出价时引擎先提取金额，再按阶梯决策（标价 199、底价 160、每轮让 3%）：

| 轮次 | 本轮可接受价 | 买家出价 150/180/185 | 结果 |
|---|---|---|---|
| 1 | 193 | 150 | 还价 193 |
| 2 | 187 | 180 | 还价 187 |
| 3 | 181 | 185 | 成交 185 |

轮数用尽后：出价 ≥ 底价就成交，低于底价就守住。AI 回复的话术再怎么润色，也绕不过这个守卫。

```

xianyu_auto_reply/
  engine.py              回复流水线（黑名单→工作时间→接管→冷却→规则→议价→AI→默认）
  rules.py               关键词规则引擎
  bargain.py             出价提取 + 议价守卫（纯逻辑可测）

  cards.py               卡密池（原子取用 + 持久化）
  notify.py              钉钉 / 企业微信通知
  transport.py           DemoTransport（离线） / XianyuTransport（MTOP + WebSocket）
  webui.py               本地管理后台（标准库 http.server）
config.example.json / rules.example.json / cards.example.json
run_tests.py             34 项测试
DESIGN.md                市面方案调研与本项目取舍
```

## 注意事项

- 本项目为个人学习与自用工具，与闲鱼/阿里巴巴无任何隶属或授权关系；使用前请阅读平台规则，
  自动化操作存在账号风控风险，请低频、拟人化（已内置随机延迟与冷却），后果自负。
- Cookie 等同账号凭证：只存本地文件，已在 `.gitignore` 中排除 `config.json`、`cookies/`、`data/`、`logs/`。
- 平台协议会更新：传输层的入站解析做了多路兜底并保留原始帧调试空间，个别字段可能需要按实际抓包微调；
  引擎、议价、发货、后台与传输层解耦，不受影响。
- 暂未实现：扫码登录、滑块处理、商品自动擦亮、批量评价——遇到滑块/验证会停机通知，转人工处理。
